# ClassicalGuitarOntology v1.0.5

**ClassicalGuitarOntology v1.0.5** is an OWL ontology for representing Level 1 classical guitar education. It models curriculum-derived learning objectives, teaching practices, technical skills, exercises, studies, repertoire-related material, assessment criteria, posture-related concepts, guitar-part knowledge, and relations among these elements.

This release accompanies the study:

**Competency-Question-Based and Expert-Informed Evaluation of an Ontology-Driven Framework for Level 1 Classical Guitar Education**

Version **v1.0.5** is the ontology version evaluated through competency questions, SPARQL queries, SWRL rules, a posture-related instructional case study, and written semi-structured expert interviews with classical guitar teachers.

## Ontology scope

The ontology focuses on **Level 1 classical guitar education**. It represents:

- learning objectives;
- teaching practices;
- technical skills;
- exercises and studies;
- repertoire-related material;
- assessment criteria;
- body posture and guitar positioning;
- guitar parts;
- level-based instructional organization;
- semantic relations among the above entities.

The ontology does not currently implement full student-progress tracking, automated readiness assessment, or adaptive tutoring functionality.

## Version information

The previously published public release was **v1.0.0**. Intermediate versions **v1.0.1–v1.0.4** were local working versions used during ontology refinement and were not published as separate GitHub releases. Version **v1.0.5** is therefore the next public release after v1.0.0 and the current public version associated with the expert-informed evaluation study.

## Use in the present study

In the associated study, the ontology is evaluated through:

- ontology requirements;
- competency questions;
- SPARQL query-based retrieval;
- SWRL rule-based reasoning examples;
- a posture and guitar-positioning instructional case study;
- expert-informed validation through written semi-structured interviews.
