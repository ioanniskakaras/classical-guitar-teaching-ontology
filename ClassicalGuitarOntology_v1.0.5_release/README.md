# ClassicalGuitarOntology v1.0.5

**ClassicalGuitarOntology v1.0.5** is an OWL ontology for representing curriculum-derived knowledge in Level 1 classical guitar education. It models learning objectives, teaching practices, technical skills, exercises, studies, repertoire-related material, assessment criteria, posture- and guitar-positioning concepts, guitar-part knowledge, level membership, and semantic relations among these elements.

## Relationship to the associated qualitative study

This release is the underlying ontology version referenced in the study:

**Classical Guitar Teachers’ Perceptions of the Pedagogical Value and Limitations of an Ontology-Driven Framework for Level 1 Instruction: A Qualitative Thematic Study**

The study examined how nine classical guitar teachers interpreted a teacher-facing representation of the Level 1 ontology-driven framework. Participants encountered the framework through a nine-slide Greek-language presentation, an analytical Level 1 curriculum-to-ontology mapping appendix, and a self-administered six-question Greek-language qualitative questionnaire.

Participants did not inspect the OWL file in Protégé, assess competency questions, execute SPARQL queries, examine SWRL rules or reasoner outputs, interact with a functioning ontology-derived application, or complete a separately administered posture and guitar-positioning case study.

Accordingly, the associated study reports teachers’ perceptions of the pedagogical value, limitations, representational clarity, and anticipated usability of the presented framework. It does not establish the formal correctness or logical consistency of the OWL artifact, SPARQL or SWRL performance, application usability, classroom effectiveness, or effects on student learning.

## Ontology scope

The ontology focuses on **Level 1 classical guitar education**. It represents:

- learning objectives;
- teaching practices;
- technical skills;
- exercises and studies;
- repertoire-related material;
- assessment criteria;
- body posture and guitar positioning;
- guitar parts;
- level-based instructional organization;
- semantic relations among the represented entities.

## Functional and evidential limitations

The ontology does not currently implement:

- full student-progress tracking;
- automated readiness assessment;
- adaptive tutoring;
- a functioning teacher-facing application;
- demonstrated effects on classroom practice or student learning.

The availability of the OWL artifact should not be interpreted as evidence that all represented pedagogical relations have been technically or empirically validated.

## Version information

The previously published public release was **v1.0.0**. Intermediate versions **v1.0.1–v1.0.4** were local working versions used during ontology refinement and were not published as separate GitHub releases.

Version **v1.0.5** is therefore the next public release after v1.0.0 and the ontology version underlying the participant-facing representation examined in the associated qualitative study.
