# Changelog

## v1.0.5 – July 2026

This release is the ontology version evaluated in the competency-question-based and expert-informed validation study of the Level 1 classical guitar education ontology.

The previously published public release was v1.0.0. Intermediate versions v1.0.1–v1.0.4 were local working versions used during ontology refinement and were not published as separate GitHub releases. Version v1.0.5 is therefore the next public release after v1.0.0.

### Main changes from v1.0.0

- Refined ontology annotations and bilingual documentation.
- Updated ontology version metadata to v1.0.5.
- Revised class and property structures for Level 1 classical guitar education.
- Improved representation of curriculum-derived learning objectives, teaching practices, studies, repertoire-related material, evaluation criteria, skills, posture-related concepts, and guitar-part knowledge.
- Prepared the ontology for competency-question-based evaluation.
- Prepared the ontology for SPARQL query testing and SWRL rule examples.
- Prepared the ontology for the posture-related instructional case study.
- Prepared the ontology for expert-informed validation through written semi-structured interviews with classical guitar teachers.
