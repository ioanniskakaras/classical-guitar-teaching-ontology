# Changelog

## v1.0.5 — 5 July 2026

Version v1.0.5 is the current public Level 1 release of ClassicalGuitarOntology.

The previously published public release was v1.0.0. Intermediate versions v1.0.1–v1.0.4 were local working versions used during ontology refinement and were not published as separate GitHub releases.

### Main changes from v1.0.0

- Refined ontology annotations and bilingual documentation.
- Updated ontology version metadata to v1.0.5.
- Revised class and property structures for Level 1 classical guitar education.
- Improved the representation of curriculum-derived learning objectives, teaching practices, technical skills, exercises, studies, repertoire-related material, assessment criteria, posture-related concepts, and guitar-part knowledge.
- Improved the explicit representation of semantic relations among Level 1 instructional entities.

### Documentation clarification — 10 August 2026

- Clarified the distinction between the OWL ontology artifact and the teacher-facing representation examined in the associated qualitative study.
- Removed the inaccurate claim that participants evaluated the ontology through competency questions, SPARQL queries, SWRL rules, reasoner outputs, a functioning application, or a separately administered posture case study.
- Clarified that the qualitative study examined teachers’ perceptions of a presentation and analytical curriculum-to-ontology mapping.
- Replaced references to semi-structured interviews with the more precise description of a self-administered written qualitative questionnaire.
- Clarified that the study’s supplementary materials are provided separately from the ontology release.

The OWL ontology file was not changed as part of this documentation clarification.
